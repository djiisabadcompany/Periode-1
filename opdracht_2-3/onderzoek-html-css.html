Onderzoek HTML & CSS.

Waarom noem je de eerste HTML-pagina meestal index.html?

De eerste html pagina is waar je begint en het is een beetje net als een boek waar je op de eerste pagina alle hoofdstukken te zien krijgt. en in het engels heet dat een INDEX.

Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

de html standard van WHATWG. hij heet de living standard omdat hij update en niet hetzelfde blijft. dus als er een update uitkomt word de standaard geupdate.

Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één CSS-versie?

omdat css altijd anders is. met andere versies die gebruikt worden die andere dingen kunnen doen omdat het modular is.

Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox, Edge of Safari?

sommige websites gebruiken andere versies html of css en daardoor kan de website anders eruit zien. omdat ze of een alternate versie laden dus stel je voor alternate fonts.
